      SECTION 13 · LIMITATIONS AND CONFIDENCE

      What this study cannot claim

      All records at Low confidence

      Every record carries confidence: Low. No LLM extraction or live API probing was performed. Classifications come from keyword detection and curated dictionaries — not authoritative structured extraction.

      9 pages failed HTTP fetch

      Salesforce, Attio, LiveAgent, Salesforce Commerce Cloud, SE Ranking, Neo4j, Binance, Paygent Connect, and PitchBook returned errors or were blocked. Their fields rely entirely on the KNOWN_* dictionaries.

      Keyword detection is imprecise

      REST detection from "rest api" in page text does not distinguish between REST API offering and REST API documentation for another product. GraphQL detection from "graphql" may catch unrelated content.

      Community MCP not researched

      The community_mcp field is Unknown for all 100 apps. A dedicated scan of community MCP registries (mcp.so, glama.ai, modelcontextprotocol/servers) is required.

      Account-plan details unverified

      Many REST APIs restrict endpoints by plan tier. Access to full API surfaces often requires paid plans, partner agreements, or account verification not visible from public documentation pages.

      Verification sample is partial

      Human verification covered 20 of 100 apps. Accuracy from the remaining 80 apps is not measured. Final accuracy requires independent review of all predictions.

      SECTION 14 · FINAL RECOMMENDATIONS

      Where to start building integrations

      🟢

      Build immediately

      Start with self-serve, API-key apps: GitHub, Stripe, Twilio, SendGrid, Datadog, Sentry, Supabase, Apify, Firecrawl, Notion, Airtable, Linear, ClickUp, HubSpot, Mailchimp, Klaviyo. All have confirmed auth, REST APIs, and no approval gate.

      🟡

      Build with caveats

      Apps with known auth and REST but plan-level or review caveats: Shopify, Slack, Zendesk, Freshdesk, Jira, Asana, Monday.com, QuickBooks, Xero, Ramp, Brex, Ahrefs. Confirm plan tier and sandbox availability first.

      🔴

      Requires vendor approval first

      Partner or admin-gated apps require explicit vendor approval before building: Google Ads, Meta Ads, LinkedIn Ads, WhatsApp Business, Amazon Selling Partner, Plaid, Salesforce Commerce Cloud, PitchBook, DealCloud.

      🟣

      Use MCP-first path

      For apps with official MCP servers, prefer the MCP integration path over raw REST: GitHub, Stripe, Notion, Jira, Datadog, Cloudflare. Official MCP servers are vendor-maintained and type-safe.
